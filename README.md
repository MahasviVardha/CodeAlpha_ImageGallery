## Luminary Gallery — CodeAlpha Internship Task 1

A beautiful, responsive image gallery built with HTML, CSS, and JavaScript.

## Live Demo
[View Live](https://luminarygallery.netlify.app/)

##  Features
- 78 images across 10 categories (Nature, Animals, Food, Anime, Art & more)
- Lightbox view with next/prev navigation
- 6 image filters — B&W, Sepia, Warm, Cool, Vivid
- Category filter bar with count badges
- Add Photo — drag & drop or URL input with live preview
- LocalStorage persistence for added photos
- Keyboard shortcuts & touch swipe support
- Fully responsive design

##  Built With
- HTML5
- CSS3 (Masonry layout, CSS Variables)
- Vanilla JavaScript

##  How to Run
1. Clone the repo
```bash
   git clone https://github.com/mahasvi-vardha/CodeAlpha_ImageGallery.git
```
2. Open `index.html` in your browser
